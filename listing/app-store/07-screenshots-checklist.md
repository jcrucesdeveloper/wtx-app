# App Store — Screenshots Checklist

Specs: `research/04-asset-specs.md`. Shot list/content plan: `assets/checklist.md`.

- [ ] 6.9" iPhone set (1290×2796 or 1320×2868px) — required
- [ ] 6.5" iPhone set (1242×2688 or 1284×2778px) — recommended for sharpness
      on that device class, otherwise Apple auto-scales the 6.9" set
- [ ] 13" iPad set (2064×2752 or 2048×2732px) — required only if the app is
      marked as running on iPad; skip if iPad support isn't enabled in the
      Capacitor/Xcode project
- [ ] App icon — 1024×1024px, no alpha, no pre-rounded corners
- [ ] (Optional) App preview video — not required; skip unless one already
      exists, don't produce one just for this submission
