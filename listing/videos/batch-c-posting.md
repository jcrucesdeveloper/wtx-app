# Batch C: what to post with each reel

The videos carry no branding on purpose (research 11). The **account name and
bio** carry WTX; the caption should sound like a person, not a product. Keep it
to one line. Never "link in bio". If you want one line of promotion, put it in
the **pinned comment**, not the caption.

Track **sends/shares** for these as well as 3 s hold and completion: a comedy
reel's job is to be forwarded.
